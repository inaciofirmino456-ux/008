# Boutique Tudo de Bom — Website Demo

Demonstração comercial criada para apresentar uma proposta de website à Boutique Tudo de Bom, loja de roupas em Luanda.

## Inclui
- Página inicial responsiva
- Coleção/destaques
- Botões de WhatsApp
- Morada e contacto
- Design para telemóvel e computador
- Estrutura pronta para substituir imagens demonstrativas pelo catálogo real

## Próxima fase
Depois de a boutique aprovar a proposta, substituir as imagens demonstrativas pelo catálogo real, adicionar produtos/tamanhos/preços e, se desejado, implementar encomenda online, domínio próprio e painel de gestão.
