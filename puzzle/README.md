# Bitcoin Puzzle Lab (seguro)

Este diretório contém um laboratório educativo de puzzles de chave **toy**. Ele demonstra a mecânica de procurar uma chave num intervalo pequeno sem apontar para carteiras reais ou endereços com fundos.

## Executar

```bash
python3 puzzle_solver.py
```

O alvo padrão é gerado pelo próprio programa a partir de uma chave privada toy conhecida. Para usar um alvo diferente, mantenha-o dentro do laboratório controlado.

> Não use este código para procurar chaves privadas de carteiras de terceiros ou para tentar obter fundos.
